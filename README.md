# REACT-MONO-REPO

## PRE-REQUISITE:

Below softwares should be installed:

- Node 18 or above
- NPM (Node package manager)

## Installation

To install and run String Calculator locally, follow these steps:

1. **Clone the repositiory:**

```sh
git clone https://github.com/ay704214011/react-mono-repo.git
cd REACT-MONO-REPO
```

2. **Install dependencies**
   ```sh
   npm install
   ```
2. **Build**
   ```sh
   npm run build
   ```

3. **Run test cases**
   ```sh
    npm run test
    ```
